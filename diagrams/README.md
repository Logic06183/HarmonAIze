# HarmonAIze Promotional Diagrams

This directory contains professional diagrams for understanding and promoting HarmonAIze, an open-source toolkit for harmonizing climate and health data.

## About HarmonAIze

**HarmonAIze** is a powerful platform that enables researchers to:
- Harmonize health data from multiple studies
- Integrate satellite climate data (40+ years from Google Earth Engine, MODIS, Landsat)
- Link environmental exposures to health outcomes
- Preserve privacy through federated approaches
- Use AI-assisted workflows to accelerate research

## Usage Guidelines

### Formats
- **SVG**: All diagrams are provided as scalable vector graphics (SVG) for maximum flexibility
- **Editing**: SVG files can be opened in design tools like:
  - Adobe Illustrator
  - Figma (drag & drop)
  - Inkscape (free, open source)
  - Web browsers (for viewing)

### Export Options
From SVG, you can easily export to:
- PNG (for web/presentations)
- PDF (for publications/print)
- JPG (for general use)

### Color Schemes
All diagrams use consistent, professional color palettes:
- **Blues**: #0B4F6C, #2E86AB, #5BA4CF (health, primary theme)
- **Greens**: #2D6A4F, #52B788, #95D5B2 (climate, environment)
- **Purple**: #7B1FA2, #9C27B0 (integration, AI)
- **Orange**: #F77F00 (accents, highlights)

Colors are colorblind-friendly and maintain strong contrast ratios for accessibility.
